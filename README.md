# [뉴욕 택시 이용기록 기반 도로 플로우 시각화 대시보드](https://hollyriver.github.io/NYCTaxiDash/)

&nbsp;Kaggle의 NYC Taxi Trip Duration 데이터 기반으로 제작된 인터랙티브 대시보드입니다. 데이터베이스나 서버와의 연결 없이 정적으로 동작합니다. 2016년도 상반기 뉴욕시의 교통 혼잡 지역 및 혼잡 시간을 두 개의 지도(Map) 레이어를 통해 시각화합니다.

## 구성

| 메인 지면 | 시각화 조합 | 방식 |
|---|---|---|
| **도로 플로우 지도** | 주중/주말/전체 × 시간대 4구간(새벽/오전/오후/저녁) 및 전체 시간 — 15개 조합 | OSMnx 최단경로 14,339건을 빌드 타임에 사전 집계하여 표시 |
| **헥스빈 히트맵** (~240m 단위 셀) | 요일 멀티선택 × 시간 슬라이더 — 전 조합 | 집계된 원본 전량(슬림 JSON)을 브라우저에서 실시간 재집계 |

- 도로 플로우는 **선 굵기 = 통행량(n), 색 = 세그먼트 평균 속력(정체 정도)** 로 두 지표를 분리 표현. 색은 속력 기준 고정 램프로 느릴수록 검붉게(정체) → 빠를수록 초록(원활) — 넓은 간선은 통행이 많아 굵어도 안 막히면 초록으로 표시됨. 굵기·투명도는 슬라이스별 통행량 분위수로 동적 구성. 플로우 시간대(밴드) 선택 시 해당 시간 트립만으로 KPI·히스토그램 강조가 갱신됨
- 헥스빈 히트맵은 **승차 지점·시각 기준** 집계 — 밀도 = 셀 내 승차 건수, 평균 속력 = 그 셀에서 출발한 트립들의 전체 구간 평균 속력. 이용 밀도 / 평균 속력 표시 전환 가능. 밀도 색상 스케일은 선택된 요일·시간 슬라이스의 분위수(p50/p85/p98)로 매번 동적 구성 — 희소 선택에서도 대비 유지. 평균 속력은 정체(저속)일수록 검붉게 표현하며 색 가시성을 위해 투명도 없이 불투명. 표본 수는 투명도로 겹쳐 표시하지 않고 밀도 표시·hover 팝업으로 확인
- 지도 좌상단 범례가 현재 레이어·지표의 인코딩을 표시 — 플로우는 평균 속력(색 램프)과 통행량(실제 선 굵기·투명도를 잇는 연속 쐐기), 헥스빈은 속력 또는 밀도(색 램프)와 하단 집계 기준 한 줄(밀도: 승차 지점·시각 기준 / 속력: 트립 전체 구간 평균). 통행량·밀도 눈금은 지도 paint 표현식의 분위수 스톱을 그대로 읽어 슬라이스·선택마다 갱신
- 슬라이스 전환·초기 로딩 중에는 지도 위에 로딩 표시(불러오는 슬라이스명 포함)를 띄우고 실제 렌더 완료 시 해제. 로드 실패 시 실패 슬라이스를 명시하고 같은 버튼 재선택으로 재시도
- Plotly 차트 2종: 요일×시간 평균 속력 히트맵(전역), 시간대별 트립 수(선택 요일 연동)

## 데이터 정제

[Kaggle NYC Taxi Trip Duration](https://www.kaggle.com/c/nyc-taxi-trip-duration) 데이터의 표본 14,587건(2016-01~2016-06). 원본 CSV(`data/NYCTaxi.csv`)는 리포지토리에 동봉.

정제 후 **14,446건** 사용 (141건 제거):

- NYC 대역 밖 좌표 (BBOX: 위도 40.50–41.00, 경도 -74.30~-73.60)
- 소요시간 60초 미만
- 직선거리 0.05 km 이하 또는 60 km 초과
- 직선거리 기준 평균 속력 120 km/h 초과

속력·거리 지표는 **OSM 도로망 최단경로 길이 기준**(14,446건 중 라우팅에 성공한 14,339건만 해당). 미라우팅 107건은 버리지 않고 직선거리 기준 유지. 평균 속력 17.5 km/h, 평균 이동거리 4.18 km.

## 주요 관찰

- 평균 속력: 종합적으로 15시가 최저속 시간대 (14.4 km/h), 그 다음은 09시 (14.5 km/h)
  * 주중 최저 속력 시간대는 09시에 554건 (13.2 km/h). 해당 시간대 주말 평균 속력이 20.1 km/h로 높은 수준에서 형성되어 있으므로, 종합 계산에서 상쇄된 것으로 보임.
  * 주말 최저 속력 시간대는 13시와 15시에 각각 202, 206건 (16.1 km/h)
- 택시 이용 빈도: 18시 912건, 19시 903건으로 피크. 최저인 새벽 5시 150건의 약 6배에 해당
- 장거리 트립: 도로망 거리 상위 10%(9.0 km 이상, 평균 15.4 km)의 평균 속력은 29.4 km/h로 나머지(16.2 km/h)의 약 1.8배. 이 중 25.0%는 JFK, 35.5%는 라과디아 공항행 — 도로 플로우 레이어에서 공항 방면 간선이 굵게 잡히는 이유를 설명 가능

## 한계

1. **속력은 하한 추정치** — 도로망 최단경로 길이 / 소요시간 기준. 최단경로는 실주행 경로보다 짧거나 같으므로 실제 속력은 이보다 높을 수 있음.
2. **최단경로 ≠ 실주행 경로** — 도로 플로우는 OSM 도로망 최단경로로 추정한 것이며 기사가 실제 택한 경로가 아님.
3. **세그먼트·셀 속도는 근사치** — 플로우 색으로 쓰는 세그먼트 평균 속력은 그 도로를 지난 트립들의 전체 평균 속력(트립 전체 구간 기준)이며, 그 구간을 실제로 통과한 속도가 아님. 헥스빈 평균 속력도 그 셀에서 출발한 트립들의 전체 평균이며 셀 안의 주행 속도가 아님.
4. **2016년 표본** — 현재 교통 상황과 다를 수 있음.
